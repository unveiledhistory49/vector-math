# Vector Math

A standalone, publication-grade STEM vector diagram studio for mathematics, geometry, algebra, and statistics. Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Vite**.

- **Live URL**: [https://vector-math.vercel.app](https://vector-math.vercel.app)
- **Suite Family**: [Vector Physics](https://vector-physics.vercel.app) · [Vector Chem](https://vector-chem.vercel.app)

---

## Generators Included

1. **Geometric Triangles**: Right, isosceles, equilateral, and scalene triangles with side lengths, angle arcs, right-angle markers, and altitudes.
2. **Quadrilaterals & Polygons**: Rectangles, parallelograms, and trapezoids with altitude lines, congruence tick marks, and diagonals.
3. **3D Solid Geometry**: Cylinders, cones, spheres, prisms, and pyramids with dashed hidden edges, radii, heights, and slant heights.
4. **Parallel Lines & Transversals**: Two parallel lines cut by a transversal with 8 angle sectors, angle arcs, and algebraic expressions ($2x + 10^\circ$).
5. **Cartesian Coordinate Grapher**: Full coordinate grid with integer ticks, linear equations ($y = mx + b$), points, and slope triangles ($\Delta y / \Delta x$).
6. **Real Number Line Inequality Grapher**: Calibrated number line with open/closed circles, ray arrows, and compound intervals.
7. **Box and Whisker Plots**: Five-number summary visualization (Min, Q1, Median, Q3, Max) with calibrated axis and summary labels.

---

## Features
- **3× High-DPI PNG Copying**: Directly rasterizes SVG onto offscreen canvas and writes to clipboard.
- **Clean SVG Downloads**: Sanitized XML for publication or editing.
- **Stateless Sharing**: Encodes state into URL search parameters.
- **Print Styles**: Formatted for classroom handouts and quiz worksheets.
